### Installation

{% stepper %}
{% step %}
### Install resource

Each minimap has its own drawer. Place it inside your server's resources folder and make sure the folder name is correct.\
**Example**: `fst_vintage_minimaps_drawer`\
Add the resource to your `server.cfg` if needed
{% endstep %}

{% step %}
### Install Assets

Each minimap has its own assets. Place them inside your server's resources folder and keep the correct folder names.

**Example**: `fst_vintage_minimaps_assets`

{% hint style="warning" %}
Note: Some minimaps have multiple asset folders. For example, the Vintage Minimap also has separate Cayo Perico assets: `fst_vintage_minimaps_cayo_assets`.

Make sure to install all required assets and keep their original folder names.
{% endhint %}
{% endstep %}

{% step %}
### Hud Colors

{% hint style="info" %}
(Optional) Install and start [`ox_lib`](https://github.com/overextended/ox_lib) before this resource if you want to use the `/mapcolors` command.
{% endhint %}
{% endstep %}

{% step %}
### Adjust your needs

Adjust `config.lua` to your liking and restart the resource.
{% endstep %}

### Using with Enhanced Minimap V2

{% hint style="warning" %}
If you own **fst\_enhanced\_minimap\_v2** and want to use one of this minimaps with it, follow this guide
{% endhint %}

{% stepper %}
{% step %}
### Set compatibility

To avoid conflicts with Enhanced Minimap V2, remove any old minimap drawers from your server.

For example, delete the old `fst_colored_minimaps_drawer` and keep only the required assets:

* `fst_colored_minimaps_assets`
* `fst_colored_minimaps_cayo_assets`

Make sure you keep the correct resources installed according to the new documentation.
{% endstep %}

{% step %}
### Ensure both resources

```cfg
ensure fst_enhanced_minimap_v2
ensure fst_colored_minimaps_assets
ensure fst_colored_minimaps_cayo_assets
```
{% endstep %}

{% step %}
### Restart your server.

{% hint style="info" %}
The Colored Minimap Bundle will only provide its textures and overlays while Enhanced Minimap handles all UI, radar, tablet, and player features.
{% endhint %}
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
If you are not using Enhanced Minimap: Make sure to **install** `fst_colored_minimaps_drawer` \
The Colored Minimap Bundle will run independently with all features enabled.
{% endhint %}

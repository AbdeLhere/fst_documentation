**i have some extra maps, can i include them ?**
{% endcolumn %}

{% column width="66.66666666666667%" %}
{% hint style="info" %}
We only include extra maps when a usable minimap is already available.
{% endhint %}

{% hint style="warning" %}
If the creator does not provide a minimap and one needs to be created from scratch, it will require a separate quote.
{% endhint %}

We do not create third-party map minimaps from scratch unless specifically agreed beforehand.

# Overview

### What We Can Do

* Custom map designs
* Extra maps such as Cayo, bridges, etc.
* Zone names
* Postals
* Street names
* Highway / route overlays
* POI icons
* Custom zones and jurisdictions
* Handmade overlays
* Custom map keys
* Configurable overlays
* PSD source files
* Or any other systems and ideas you got in mind

### What You Receive

* Fully working FiveM minimap
* Clean and optimized files
* Ready-to-install resource
* Setup support if needed

### How It Works

1. You tell us what maps and features you need.
2. We make a summary with the final price.
3. You confirm the project.
4. The design is created.
5. We make the minimap work with FiveM.
6. You receive the final files.

For commissions, contact us on Discord.
